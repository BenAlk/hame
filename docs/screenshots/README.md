# Screenshots

Capture list for the images the root [`README.md`](../../README.md) embeds. Save each with the
exact filename below (PNG) in this folder and it slots straight into the README — no README edits
needed. Until a file lands, its README image shows as a broken-image placeholder with alt text.

Shoot the wall tablet in **landscape** and the phone in **portrait**. Use the demo seed
(`pnpm db:seed`) for a full-looking dashboard/calendar, or your live instance for the richest result
(real weather, smart-home, Immich screensaver). Crop to the app — no browser chrome or desktop.
